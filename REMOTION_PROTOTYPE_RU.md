# Studio 9.0 Preview

- Сборки тестового канала публикуются отдельными prerelease с тегом preview-v9.0.x, контрольной суммой SHA-256 и отдельным AppId. Стабильный канал не меняется.
- Для перехода с 9.0.0 на 9.0.1 требуется вручную установить тестовый установщик; далее кнопка проверки обновлений выбирает только preview-релизы.
- Импорт .CUBE проверяет количество строк 3D LUT, сохраняет локальную копию в LocalAppData/CapCutAutoEditor/remotion/luts. При возможности переносит ранее выбранный файл автоматически.
- Цветокоррекция повторяющихся футажей кэшируется по содержимому и параметрам, включая SHA-256 LUT; лимит кэша 3 ГБ. На пользовательском ПК до 4 потоков рендера, в CI 2. Реальный выигрыш зависит от исходников, GPU и CPU.
- Отдельный установщик включает Node.js, Remotion, Chromium и FFmpeg. Настройки, песни и проекты общие с предыдущей версией. Не запускать обе версии одновременно.
- Оформление текста и переходов приблизительно воспроизводит CapCut; точное визуальное совпадение и ускорение ещё проверяются.

- 9.0.2: отдельные профили Inter Tight SemiBold Italic и Onest SemiBold, проверка семейства, веса и покрытия текста, импорт локальных TTF/OTF в настройках. Chromium ждёт подтверждения загрузки FontFace. Уже экспортированные MP4 не изменяются; новые рендеры используют новую ревизию движка.

- 9.0.4: уникальные имена ресурсов по SHA-256, фиксированный вес вариативных шрифтов, запись фактического семейства/начертания/хеша в журнал. Перед рендером Canvas сравнивает отрисовку кириллицы с системным fallback. Проверка не заменяет визуальное сравнение двух реальных экспортов.

## TikTok Factory 10.0.0
Новые проекты создаются в отдельном локальном каталоге factory_projects без установленного внешнего редактора. Сохранённые ZIP используются только для переноса стиля; если их нет, встроены стили двух аккаунтов. Старые папки, данные и AppId сохранены. Рендер подписей из точных TTF/OTF через FreeType в PNG, Remotion композитит прозрачные слои. Окно готовых экспортов: дата, время, фильтры, статусы из журнала доставки. Публикация через preview-релизы.
