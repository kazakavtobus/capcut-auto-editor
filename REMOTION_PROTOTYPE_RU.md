# Studio 9.0 — экспериментальная ветка Remotion

Не устанавливать поверх стабильной версии до проверки. Ветка studio-v9-remotion не публикует релиз.

- Два движка на странице монтажа: Remotion (фоновый прототип) и резервный CapCut.
- Движок читает локальный draft_content.json и AutoAssets, не открывает CapCut. Сохраняет монтажные тайминги, звук, субтитры и имя шрифта из эталона. Пять футажей и история остаются в прежнем Python-конвейере.
- В тестовом установщике поставляются Node.js 22, зависимости Remotion и проверенный Chrome Headless Shell. Установка Node/npm вручную не нужна. При запуске из исходников без установщика нужен Node.js 22+ с npm и интернет для первой установки зависимостей. Используются установленные на ПК шрифты. В монтаже кнопка «Выбрать LUT» позволяет выбрать локальный Clayton 33.CUBE. Ни один частный файл не включён в репозиторий.
- Цветокоррекция: оригинальный локальный LUT через FFmpeg, приблизительная яркость/контраст. CSS-анимация появления/затухания и размытие приближены к эталону; не являются точной копией CapCut. Размер текста приблизительно откалиброван по примерам. Рендер 1080×1920, 30 FPS, H.264/AAC. Аппаратное кодирование запрашивается только после успешного пробного кодирования NVENC системным FFmpeg. Если рендер с GPU падает, выполняется одна повторная попытка на CPU. В CI явно используется CPU.
- Проверенный MP4 проходит прежний механизм публикации, создаёт export.json, появляется в отгрузке. Никаких автоматических отправок.
- Тест CI использует только искусственные исходники. Для сравнения с реальными эталонами нужен локальный тест с исходными футажами и шрифтами. Не утверждаем, что кадры совпадают один в один.
- Проверка: GitHub Actions → Remotion prototype smoke. Артефакт MP4 появляется после успешного реального теста. Ветка собирает тестовый установщик как артефакт Actions, без публикации стабильного релиза. Установка в отдельную папку, данные Studio общие со стабильной версией: перед тестом сделайте резервную копию локальных настроек/медиатеки и не запускайте обе версии одновременно.
