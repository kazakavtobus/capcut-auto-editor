# CapCut Auto Editor V7.5 — библиотека песен и подготовка GitHub Releases

Windows-приложение на PySide6. Из MP3 автоматически собирает редактируемый проект CapCut из трёх видео с субтитрами. Источник видео — экспериментальный Pinterest; подбор одной темы на ролик, исключение повторных исходников на 7 дней.

## Новое в V7.5

- **Библиотека песен:** `%LOCALAPPDATA%\CapCutAutoEditor\song_library`. Для каждой песни запоминаются все слова, фразы, начальные и конечные таймкоды и статус проверки. Идентификатор — SHA-256 **самого аудиофайла**, а не его имени. Переименование файла не сбрасывает правки; изменённая перекодировкой запись может считаться новой песней.
- **Приоритет ручных правок:** после «Сохранить в проект» в редакторе субтитры помечаются как проверенные. При загрузке того же MP3 вручную проверенные слова и тайминги подставляются сразу; повторное распознавание не делается. Если текст когда-то распознала только машина, новый монтаж может попробовать распознать его заново.
- **Импорт исправлений из CapCut:** закрой редактор CapCut, открой в нашей программе «Редактор субтитров», выбери соответствующую папку проекта и нажми «Запомнить правки CapCut». Сохранятся именно текущие текст и времена проекта. Перезапуск программы не сбрасывает их.
- **Визуальный редактор:** настоящая волна звукового файла, прослушивание, позиция воспроизведения, выбор фразы и перетаскивание её границ на таймлайне. Таблица позволяет добавлять, дублировать, удалять и редактировать субтитры. Сохраняет редактируемые текстовые блоки CapCut.
- **WhisperX (опционально):** более точное выравнивание слов на основе русского вокала после распознавания. В редакторе кнопка «Уточнить тайминги (WhisperX)» делает только предварительные изменения в таблице — их надо проверить и сохранить. Если WhisperX недоступен, остаются таймкоды Whisper. Существующие подтверждённые исправления **никогда** автоматически не переписываются. Для песен без текста по-прежнему используется двухпроходный faster-whisper; опционально — Demucs для выделения вокала (в Python-версии).
- **Приватность:** библиотека, шаблон CapCut, модели и профиль Pinterest находятся вне программы. Они не добавляются в публичный GitHub и не стираются при обновлении.

## Установка без повторного скачивания моделей

При переходе с V7.4 достаточно распаковать маленький `Update_Only.zip` в существующую папку **при закрытой программе** и заменить файлы. Не удаляй `.venv`, пользовательскую папку `%LOCALAPPDATA%\CapCutAutoEditor` и сохранённые модели Whisper/Demucs. Для полной установки запусти `install.bat`, затем `start.bat`.

### Дополнительное выравнивание таймингов

`install_alignment.bat` устанавливает WhisperX в **локальное Python-окружение**. Это необязательный тяжёлый ML-пакет (модели загружаются отдельно). Установка может занять время или завершиться ошибкой совместимости. Автоматический монтаж продолжит работать через faster-whisper без него. В первой EXE-сборке WhisperX и Demucs не упаковываются: основная автоматизация работает, но сложные ML-опции доступны только в Python-режиме с установленными пакетами.

В редакторе:
1. Открой созданный проект CapCut и нажми на блок в таблице или на волне.
2. Прослушай нужный фрагмент; границы блоков можно перетаскивать за края цветной полосы.
3. Исправь слова и тайминги и нажми «Сохранить в проект», предварительно **закрыв CapCut**.
4. Создай второй монтаж с **тем же файлом песни**: программа автоматически получит сохранённые проверенные слова и тайминги, но найдёт новые видео (ограничение 7 дней).
5. Если исправлял субтитры непосредственно в CapCut — используй «Запомнить правки CapCut» после закрытия CapCut.

## Подготовка GitHub / EXE

Исходный пакет `Source_GitHub.zip` **НЕ содержит** `template_original.zip`, локальных музыкальных файлов, MP4, секретов и данных браузера. Сам личный шаблон из предыдущего релиза хранится в локальном ZIP пользователя; в новой установленной EXE-версии нужно **один раз** импортировать его через настройки. Не выкладывай полный локальный архив публично.

1. Создай пустой репозиторий **`kazakavtobus/capcut-auto-editor`**. Для работы обновлений без авторизации он должен быть публичным, либо потребуется другой механизм доступа. Не используй другой свой репозиторий, чтобы не смешать проекты.
2. Залей туда содержимое **Source_GitHub.zip**, убедись, что каталог `.github/workflows` включён.
3. Открой GitHub **Actions → Windows EXE + Installer release → Run workflow**. Это пробная Windows-сборка. Если тесты/упаковка провалятся, изучи логи и исправь до релиза.
4. После успешного Windows-билда добавь тег `v7.5.0` в этот коммит и отправь на GitHub. Workflow соберёт и при успехе опубликует Release c `CapCutAutoEditor_Setup.exe` и `.sha256`.
5. С этого момента кнопка «Проверить обновления» сможет видеть **последующие** релизы, скачать официальный установщик и проверить SHA-256. Пока GitHub Release не опубликован, обновлятор работать не будет.

**Важно:** сборка EXE, запуск реального Qt на Windows, GitHub Actions/Release и загрузка через Pinterest пока **не проверены здесь**. Это release candidate, не гарантированный установщик. Windows SmartScreen может предупредить о неподписанном EXE.

### Диагностика

Основной журнал: `%LOCALAPPDATA%\CapCutAutoEditor\logs\app.log`. Нативные аварии: `native_faults.log`. Если программа падает, отправь последние строки логов (без приватных путей/ключей). Исходники Python и тесты находятся в GitHub-архиве.

### Право на материалы

Pinterest может ограничивать автоматический доступ; скачанные видео не обязательно разрешены для повторной публикации. Для роликов используй видео с подходящей лицензией или полученным разрешением.
